# plasmoid-musewidge

This is a plasmoid widget that uses playerctl to get the currently playing item's title and artist information.

Designed for use in a taskbar, but can  be used anywhere plasma allows widgets.

Issues:
- zero customization of read data
- alignment is always right, in some situations text displays over other things
- layout issues kind of the cause of above

Working:
- automatic and specified player support, e.g can specify only spotify to be read from.
